Polycards Deck Import Tool

Paste your word lists, check them, and get SQL to run in the Supabase SQL editor. Nothing is sent anywhere except read-only look-ups of your public library.

1. Your word list

Paste CSV text, or copy the cells straight from Google Sheets (including the header row). Columns: school_level, textbook, unit_order, unit, deck, collection, english, japanese, reading, alt_answers, example_en, example_ja, pos, speak_as, source, note. Only english, japanese and deck are always required. reading is the Japanese meaning written in hiragana, for kana search (for example かりる for 借りる): the same text with kanji and katakana in hiragana, punctuation kept. Every new word should have one. Katakana is saved as hiragana, and a word that already has a reading in the library keeps it. alt_answers is optional: other English answers that typing and handwriting mode should also accept, separated by ; (for example cute; beautiful). Alternates are only ever added to a word, never removed. example_en and example_ja are an optional example sentence and its Japanese translation (give both or neither). pos is the optional part of speech: noun, verb, adjective, adverb, preposition, pronoun, conjunction, auxiliary (or auxiliary verb), article, interjection, number, phrase, or the Japanese 名詞 動詞 形容詞 副詞 前置詞 代名詞 接続詞 助動詞 冠詞 間投詞 数詞 表現. A word that already has a part of speech in the library keeps it. speak_as is optional: what the recorded pronunciation should say instead of the English, for words spelled the same but said differently (for example red for read 読んだ). It is only filled in for words that don't have one yet. source and note are ignored.
